# レシピ帳

自分で作っておいしかった料理だけを、写真・材料と調味料の分量・作り方・作った日と一緒に残すWebアプリです。

- 公開ページ: https://yumapons.github.io/recipe-note/
- データは使う人それぞれのブラウザ（IndexedDB）に保存され、ほかの人には見えません
- 設定画面から全レシピを写真ごとファイルに書き出し・読み込みできます
- 演出の一部は [Motion Prompt](https://showheyohtaki.github.io/motion-prompt/)（MIT License © 2026 Shohei Ohtaki）の #166 #096 #056 #072 をもとにしています
